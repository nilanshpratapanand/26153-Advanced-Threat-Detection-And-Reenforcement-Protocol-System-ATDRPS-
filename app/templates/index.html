Analyse a capture

Accepts a PCAP/PCAPNG capture or a flow CSV (CIC-IDS2018, CIC-IDS2017, UNSW-NB15, CTU-13). Nothing leaves this machine.

What this is doing

A conventional IDS labels each flow benign or malicious. ATDRPS instead groups traffic into fixed time windows, encodes each window as a 96-dimensional network state, and learns how those states evolve. It then rolls that model forward K steps to estimate whether the network is heading toward compromise, maps the predicted state to a MITRE ATT&CK stage, and reports the measurements that drove the call.
