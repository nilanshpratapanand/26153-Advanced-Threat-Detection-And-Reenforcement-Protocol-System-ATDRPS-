What this is doing

A conventional IDS labels each flow benign or malicious. ATDRPS instead groups traffic into fixed time windows, encodes each window as a high-dimensional network state, and learns how those states evolve — a world model, P(St+1|St). It then rolls that model forward K steps to estimate whether the network is heading toward compromise, maps the predicted state to a MITRE ATT&CK stage, and reports the measurements that drove the call.
